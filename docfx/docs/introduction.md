# Jitter2 documentation

Learn to build a simulation with Jitter2, then explore the engine's bodies, shapes, and constraints. Use the navigation on the left to browse the tutorials and reference guides.

## Start with a tutorial

- **[Falling boxes](tutorials/boxes/project-setup.md)** — Set up a .NET project, add a render loop, and simulate your first falling boxes.
- **[Teapot stacking](tutorials/teapots/project-setup.md)** — Load convex hulls and build a tower of teapots.
- **[Two boxes and a hinge](tutorials/hinge/project-setup.md)** — Connect bodies with a joint and render the scene through Jitter's debug drawer.

## Understand the engine

- [General concepts](documentation/general.md): collision detection, precision, determinism, and math conventions.
- [World](documentation/world.md): create and step a simulation.
- [Rigid bodies](documentation/bodies.md) and [shapes](documentation/shapes.md): define the objects in your world.
- [Constraints](documentation/constraints.md): connect bodies and restrict their motion.
- [Arbiters](documentation/arbiters.md), [dynamic tree](documentation/dynamictree.md), and [collision filters](documentation/filters.md): work with contacts and collision queries.
