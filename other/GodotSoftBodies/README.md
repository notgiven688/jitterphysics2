## Jitter2 Soft Bodies in Godot

Twenty-five soft-body tetrominoes fall and collide on a floor. Jitter2 simulates
the tetrahedral cells, and Godot draws their deforming outer surfaces.

Open `project.godot` in [Godot 4.7.2 .NET](https://godotengine.org/download/archive/4.7.2-stable/)
with the .NET 8 SDK or newer installed, then press **F5**. The project restores
[Jitter2 2.15.0](https://www.nuget.org/packages/Jitter2/2.15.0) from NuGet.
Click **Reset scene** to start the drop again.
