Remarks

Both drawing methods must be implemented. A wireframe drawer can draw triangles as three line segments. Use DebugDrawGeometry to generate point markers and other drawing geometry.

Remarks

Vertices are counterclockwise when viewed from the front. The front normal points along (pB - pA) x (pC - pA). Implementations may use back-face culling.
