ArrowHeadSize

Length of arrowheads in world units, independently of arrow length, GuideSize, FrameSize, and shaft thickness. Default is 0.2. Used by both solid and wire arrows. Heads are clamped to half the arrow length; their base radius is 40% of their length. Must be finite and greater than zero.

public float ArrowHeadSize { get; init; }

Property Value

float

ArrowSegments

Number of segments around each arrowhead base and solid shaft, from 3 to 256. Default is 12. A value of 4 draws a square base; higher values approximate a circle. Wire arrows connect every base vertex to the tip.

public int ArrowSegments { get; init; }

Property Value

int

ArrowShaftRadius

Radius of solid arrow shafts in world units, independently of arrow length, GuideSize, and FrameSize. Default is 0.025. Must be finite and greater than zero. The radius is clamped to 5% of the arrow length and half the arrowhead's base radius. Wire arrows are unaffected.

GuideSize

Radius of angular guides and half extent of plane patches, in world units. Also sets constraint arrow lengths and marker sizes. Coordinate frames use FrameSize instead. Arrowheads and shafts use ArrowHeadSize and ArrowShaftRadius independently. Physical distances and linear limits are never scaled. Must be finite and greater than zero. Default is 1.
