DrawSolidArrow(IDebugDrawer, JVector, JVector, float, uint, int)

Draws a closed solid arrow with a cylindrical shaft and a cone head.

public static void DrawSolidArrow(this IDebugDrawer drawer, JVector origin, JVector vector, float radius, uint color, int segments = 12)

Parameters

drawer IDebugDrawer
origin JVector
vector JVector
radius float

Shaft radius in world units, clamped to 5% of the arrow length and half the head's base radius. Must be finite and nonnegative.

color uint
segments int

Number of sides around the shaft and head, from 3 to 4096. Default is 12.

Remarks

Triangles face outward so the arrow can be rendered with back-face culling. Zero-radius and very short arrows are represented by a segment.
