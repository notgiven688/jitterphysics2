Enum SolveMode

Namespace

Selects how the solver groups the contacts that it solves at the same time. Both modes use the same solver and produce equally valid results.

public enum SolveMode

Fields

Deterministic = 1

The contacts are grouped anew in every step, in an order that depends only on which contacts exist. The same world state then gives the same result on every run, for any number of threads and after restoring an earlier state.

Regular = 0

A contact keeps its group for as long as it exists, so only new contacts have to be grouped in a step. This is the fastest mode. The result depends on the order in which the contacts appeared, and therefore on the history of the world, not only on its current state. With several threads that order depends on timing, so two runs may differ.
