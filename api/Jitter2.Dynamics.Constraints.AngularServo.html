TargetRelativeOrientation

Gets or sets body 2's target orientation relative to body 1. Identity aligns their local frames. The value must be normalized. Changing it does not move either body.

public JQuaternion TargetRelativeOrientation { get; set; }

JQuaternion

Remarks

The servo uses the shortest rotation to the target orientation. Revolution counts are not supported.
