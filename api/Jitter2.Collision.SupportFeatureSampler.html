Remarks

This is the default implementation of SupportFeature(in JVector, float, Span<JVector>). It probes the support mapping in six directions tilted around the given one in a hexagonal pattern. A flat feature returns its vertices for these probes. A curved surface would return points beside the actual contact, by the radius times the tilt; those probes are recognized by how they move when the tilt is doubled and are extrapolated to zero tilt, which puts them on the resting point or line of the curved side.

Shapes that know their features analytically should override the query instead: the sampling costs twelve to thirty support calls.
